# ONerd — landing page

Landing page responsiva em HTML, CSS e JavaScript puro.

## Publicar no EasyPanel

1. Envie estes arquivos para um repositório GitHub.
2. No EasyPanel, crie um serviço do tipo **App** conectado ao repositório.
3. Selecione a opção de build por **Dockerfile** (o arquivo já está na raiz).
4. Configure a porta interna como `80` e faça o deploy.

## Personalizar antes de publicar

- Ajuste a grafia da marca “ONerd” conforme a identidade visual desejada.
- Atualize WhatsApp (`wa.me/5500000000000`), Telegram, email e endereço na seção Contato.
- Substitua os seis logos demonstrativos por logos autorizados dos clientes.
- Revise a descrição da empresa e os serviços para refletir a oferta real.

O repositório GitHub será a fonte do código; o EasyPanel fará o build e servirá os arquivos estáticos.

A página `404.html` é usada pelo GitHub Pages e pela configuração Nginx incluída para URLs que não existem.
